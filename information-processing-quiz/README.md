# 정보처리기사 필기 퀴즈

정보처리기사 필기시험을 공부할 수 있는 웹 기반 퀴즈 게임입니다. 기출문제를 활용하여 실전처럼 풀 수 있으며, 오답노트와 학습 기록으로 자신의 진행 상황을 추적할 수 있습니다.

## 기능

### 1. 퀴즈 시작
- 5개 과목에서 골고루 선택된 20문제를 랜덤으로 풀기
- 실시간 점수 확인
- 진행률 표시

### 2. 과목별 퀴즈
- 원하는 과목만 선택해서 풀기
- 여러 과목 동시 선택 가능
- 문제 개수 선택 (10, 20, 40, 전체)

### 3. 오답노트
- 틀린 문제 자동 저장
- 문제, 내 답, 정답, 해설, 틀린 횟수 확인
- 오답 문제만 다시 풀기
- 브라우저 종료 후에도 유지

### 4. 학습 기록
- 매번 풀이 완료 후 기록 자동 저장
- 날짜, 문제 수, 정답, 점수, 정답률 확인
- 최근 100개의 기록 보관

### 5. 문제 관리
- 등록된 문제 통계 확인
- 과목별 문제 수
- 연도별 문제 수

## 실행 방법

### 방법 1: 웹 브라우저로 직접 열기

1. 프로젝트 폴더에서 `index.html` 파일을 찾습니다.
2. 웹 브라우저(Chrome, Firefox, Edge 등)에 드래그 앤 드롭하거나 우클릭 → "프로그램으로 열기" → 웹 브라우저 선택

### 방법 2: 로컬 서버 실행 (권장)

**Python 3.x 사용 시:**
```bash
cd information-processing-quiz
python -m http.server 8000
```
그 후 웹 브라우저에서 `http://localhost:8000` 접속

**Node.js 사용 시:**
```bash
cd information-processing-quiz
npx http-server
```

## 새 문제 추가 방법

### 1. JSON 파일 편집

`data/questions.json` 파일을 텍스트 에디터(메모장, VS Code 등)로 엽니다.

### 2. 문제 추가 형식

기존 문제 아래에 다음 형식으로 새 문제를 추가합니다:

```json
{
  "id": 21,
  "year": 2025,
  "round": 1,
  "subject": "소프트웨어 설계",
  "questionNumber": 21,
  "question": "문제 내용을 여기에 작성합니다.",
  "choices": [
    "첫 번째 선택지",
    "두 번째 선택지",
    "세 번째 선택지",
    "네 번째 선택지"
  ],
  "answer": 2,
  "explanation": "정답에 대한 해설을 작성합니다."
}
```

### 3. 각 항목 설명

| 항목 | 설명 | 예시 |
|------|------|------|
| `id` | 고유한 문제 번호 (중복 불가) | 21 |
| `year` | 시험 연도 | 2025 |
| `round` | 회차 | 1, 2 |
| `subject` | 과목명 (정확히 입력) | "소프트웨어 설계" |
| `questionNumber` | 원본 시험 문제 번호 | 1-80 |
| `question` | 문제 내용 | "~입니다?" |
| `choices` | 보기 배열 (순서 중요) | ["보기1", "보기2", ...] |
| `answer` | 정답 번호 (1-4) | 2 (두 번째 선택지) |
| `explanation` | 정답 해설 | "이유는 ~입니다." |

### 4. 과목명 (정확히 일치해야 함)

- "소프트웨어 설계"
- "소프트웨어 개발"
- "데이터베이스 구축"
- "프로그래밍 언어 활용"
- "정보시스템 구축관리"

### 5. 완전한 예제

```json
{
  "id": 21,
  "year": 2025,
  "round": 1,
  "subject": "소프트웨어 설계",
  "questionNumber": 1,
  "question": "소프트웨어 설계의 목표가 아닌 것은?",
  "choices": [
    "시스템의 복잡성 감소",
    "유지보수성 향상",
    "컴파일 속도 증가",
    "확장성 보장"
  ],
  "answer": 3,
  "explanation": "소프트웨어 설계의 목표는 복잡성 감소, 유지보수성, 확장성 등입니다. 컴파일 속도는 설계가 아닌 구현 단계의 성능에 관련됩니다."
}
```

### 6. JSON 문법 확인

- 마지막 항목을 제외한 모든 항목 뒤에 **쉼표(,)** 필요
- 마지막 항목 뒤에는 쉼표 없음
- 큰따옴표(**"**) 사용 (작은따옴표는 불가)
- 텍스트는 반드시 따옴표로 감싸기
- 숫자는 따옴표 없음

### 7. 저장 후 확인

1. 파일을 저장합니다.
2. 웹 브라우저를 새로고침합니다.
3. "문제 관리" 메뉴에서 문제 개수가 증가했는지 확인합니다.

## 프로젝트 구조

```
information-processing-quiz/
├── index.html              # 메인 HTML 파일
├── css/
│   └── style.css          # 스타일시트
├── js/
│   ├── app.js             # 메인 앱 로직 (화면 전환, 메뉴)
│   ├── quiz.js            # 퀴즈 진행 로직
│   ├── storage.js         # localStorage 관리
│   └── questionManager.js # 문제 데이터 관리
├── data/
│   └── questions.json     # 기출 문제 데이터
└── README.md              # 이 파일
```

### 파일별 역할

- **index.html**: 모든 화면의 HTML 구조 정의
- **style.css**: 깔끔하고 현대적인 UI 스타일
- **app.js**: 메인 메뉴, 화면 전환, 각 페이지 렌더링
- **quiz.js**: 문제 출제, 답안 채점, 결과 계산
- **storage.js**: 브라우저의 localStorage 사용하여 오답노트, 학습 기록 저장
- **questionManager.js**: questions.json 로드, 문제 필터링, 랜덤 선택
- **questions.json**: 실제 기출문제 데이터 저장

## 사용 팁

1. **첫 실행 시**: 페이지가 로드되면 자동으로 questions.json의 문제가 로드됩니다.

2. **오답노트 활용**: 틀린 문제는 자동으로 저장되므로, 나중에 오답노트 → "오답 문제 다시 풀기"로 복습할 수 있습니다.

3. **학습 기록 추적**: 매일 같은 시간에 문제를 풀면 자신의 실력 향상을 확인할 수 있습니다.

4. **데이터 초기화**: 모든 데이터는 브라우저의 localStorage에 저장됩니다.
   - 브라우저 캐시를 삭제하면 데이터가 사라집니다.
   - 개발자 도구(F12) → Application → Local Storage에서 수동으로 삭제할 수 있습니다.
