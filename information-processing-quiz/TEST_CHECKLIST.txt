정보처리기사 필기 퀴즈 - 테스트 체크리스트
=============================================

[ ] 1. 페이지 로드
   - 메인 화면이 정상적으로 표시되는가?
   - 5개의 메뉴 버튼이 보이는가? (퀴즈 시작, 과목별 퀴즈, 오답노트, 학습 기록, 문제 관리)

[ ] 2. 퀴즈 기본 기능
   - [퀴즈 시작] 클릭 → 문제 1/20이 표시되는가?
   - 과목명이 배지 형태로 보이는가?
   - 문제와 4개의 보기가 표시되는가?
   - 진행률 바가 표시되는가?

[ ] 3. 답 선택 및 확인
   - 보기 중 하나를 클릭하면 선택된 상태로 표시되는가?
   - [정답 확인] 버튼이 활성화되는가?
   - [정답 확인] 클릭 → 정답/오답 메시지가 표시되는가?
   - 내 답, 정답, 해설이 모두 표시되는가?
   - 정답은 초록색, 오답은 빨간색으로 표시되는가?

[ ] 4. 다음 문제로 진행
   - [다음 문제] 버튼으로 다음 문제로 진행되는가?
   - 문제 번호가 증가하는가?
   - 진행률 바가 업데이트되는가?

[ ] 5. 20문제 완료 후
   - 결과 화면이 표시되는가?
   - 총 문제, 정답, 오답, 점수가 표시되는가?
   - 과목별 성적이 표시되는가?
   - [오답 확인], [다시 풀기], [메인 화면] 버튼이 있는가?

[ ] 6. 과목별 퀴즈
   - [과목별 퀴즈] 클릭 → 과목 선택 화면이 표시되는가?
   - 5개 과목 체크박스가 있는가?
   - 문제 개수 선택 옵션이 있는가?
   - 과목 선택 시 "선택된 조건의 문제: XX개"가 업데이트되는가?

[ ] 7. 오답노트
   - 틀린 문제가 저장되는가?
   - [오답노트] 클릭 → 저장된 오답이 표시되는가?
   - 각 오답 항목에 문제, 내 답, 정답, 해설이 있는가?
   - 브라우저를 새로고침한 후에도 오답이 유지되는가?

[ ] 8. 학습 기록
   - [학습 기록] 클릭 → 테이블이 표시되는가?
   - 날짜, 문제 수, 정답, 점수 등이 기록되는가?

[ ] 9. 문제 관리
   - [문제 관리] 클릭 → 전체 문제 개수(20)가 표시되는가?
   - 과목별 문제 수가 표시되는가? (각 5개)
   - 연도별 문제 수가 표시되는가?

[ ] 10. 반응형 디자인
   - PC에서 화면이 잘 보이는가?
   - 브라우저 창을 줄여도 화면이 깨지지 않는가?
